# Домашнее задание 1: Знакомство с Go и workspace

Программа на языке Go, выводящая:
1. Имя текущего пользователя операционной системы (переменные окружения `USERNAME` / `USER`).
2. Текущую установленную версию Go (`runtime.Version()`).
3. Аргументы командной строки (`os.Args[1:]`), переданные программе при запуске.

---

## Инструкция по запуску

Перейдите в директорию `hw01`:

```bash
cd hw01
```

### Запуск без аргументов

```bash
go run .
```

### Запуск с аргументами командной строки

```bash
go run . foo bar baz
```

Также запуск возможен из корневой директории репозитория благодаря `go.work`:

```bash
go run ./hw01 foo bar baz
```
